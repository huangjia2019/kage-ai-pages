研究

关于 Agent 架构的论文与框架—— Manning 那本书在工程层面论证的 thesis，在这里以更形式化的方式呈现。 核心论点：Agent 架构 = 不确定性下的有界资源分配。 模型负责消费，harness 负责预算。

框架

  • v1 · 2026 双轴框架 · AI Agent 设计模式的二维分类

    把 Agent 架构沿 认知功能（7 类） × 执行拓扑（6 种） 两个维度分类。 7×6 矩阵产生 27 个不同的 Agent 设计模式，其中 13 个由本工作首次命名。 框架以 5 条经验性的"模式选择律"收口。

  • v1 · 2026 模式进化 · 从 GoF、分布式到 Agent

    48 个软件设计模式的交互式血脉地图—— GoF 在 1994 年命名的 23 个对象模式 + 分布式系统社区在 2000s–2020s 积累的 25 个模式 → Agent 时代如何继承与升级。每个模式都是可点击的卡片，展开后呈现 原问题、默认前提、Agent 时代的对应物。 核心论点：模式没有过时，它们被抬高了一层。

  • v1 · 2026 Harness 解剖 · 八大 agent 框架横切分析

    把八个工业级 agent harness（Claude Code / Codex CLI / Aider / OpenCode / OpenClaw / Hermes Agent / DeerFlow / OpenHands）放在同一张图上看——沿 7 个认知功能逐格打分，画出覆盖热力图。背后是一套 固定的逆向五步法（Detect → Classify → Filter → Map → Verify）， 每一格都有源码文件 + 行号定锚。名单不封闭——新的 harness 可以同样喂进来。

  • v1 · 2026 范式演进 · 从结构化编程到 Agent 时代

    比模式更大的单位：范式。六个时代、十五个大范式的可交互时间线—— 结构化编程 → OOP / 模式语言 / GoF → 分布式 / CAP / REST / DDD / 事件溯源 → 微服务 / 云原生 / 响应式 → 数据密集型思维 → 大模型 / Agent 架构 / Harness 工程学。 每张卡片可点开，展示解决了什么、关键洞察、带来的思维转变三段。 只放真正在 CAP / 微服务这个级别上改变工程词汇的东西。

阅读地图

  • v1 · 2026 经典技术书与论文的定义性洞见

    一个公开阅读地图：看那些真正改变领域判断方式的书和论文， 它们各自回答了什么问题、提出了什么定义性洞见、反转了什么默认假设， 以及为什么这些思想能够传播。它不是 Agent 框架页，而是一个训练自己识别 “经典洞见”的入口。

  • v1 · 2026 长期有生命力的人类思想原则

    一张跨时代思想原则地图：苏格拉底式追问、第一性原理、无为、 奥卡姆剃刀、方法论怀疑、可证伪性、系统思维、金字塔原理、 刻意练习、暗时间等。每条都按“问题、原则、反转、练习问题”组织， 方便真正拿来启发和使用。

论文

  • 2026 年 5 月 15 日 A Two-Dimensional Framework for AI Agent Design Patterns: Cognitive Function × Execution Topology

    Huang & Zhou, 2026。arXiv 预印本 arXiv:2605.13850（cs.AI）· 归档 DOI 10.5281/zenodo.19036557。 合作者：周天翼（A*STAR CFAR）。 我们论证：仅凭拓扑或仅凭认知，都不足以区分架构上真正不同的 Agent 系统。 提出的二维分类法组织了 27 个模式，并产生 5 条经验性的模式选择律。
