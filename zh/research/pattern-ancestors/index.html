分布式时代

典型分布式模式 → Agent 后裔

GoF 假设的是单进程。分布式时代换了一套运行假设：失败是 default，不是 exception。 下面这些模式是真正进了生产手册、厂商 API 和平台工程的那一批。 每个都至少有一个 Agent 时代的后裔——有时是直接搬，有时是 reframe。
