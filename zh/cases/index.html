Agent 案例库

按两个维度组织的智能体设计案例。

这里放可运行、可观察、可复用的 Agent demo。行业场景回答“业务对象是什么”，技术专题回答“工程能力怎么被 Agent 化”。金融和质量工程方向已经有完整蓝图、截图和模式映射；法律和医疗方向先作为后续案例入口保留。

维度 01

行业场景

从业务对象出发：文档、工单、合同、病历如何进入 Agent 工作流。

金融

监管分析、工单审查、产品合规、证据链和审批门控。

法律

合同审查、政策对比、引用证据和带审批门的文书生成。

医疗

病历摘要、问询分诊、安全复核和人在回路流程。

维度 02

技术专题

从工程能力出发：质量控制、测试生成、故障诊断和度量分析如何被模式化。

质量工程

代码审查、测试生成、故障诊断、效能度量和模式选型。
