模式映射
模式设计作用
扇出/汇聚事故证据分散在多个系统，可并行查询。


多模态融合日志、指标和配置要变成一条可比较时间线。


迭代假设Agent 要测试并拒绝假设，而不只是复述症状。


可观测性 Harness每个诊断都要有轨迹、置信度和未解风险。


设计洞察
诊断不是搜索
更多日志本身没有意义，除非 Agent 有假设循环。


只读也可以很强
诊断 Agent 不执行修复，只输出证据和下一步，也能很安全。


置信度是路由信号
低置信度应该触发升级，而不是生成一段貌似自信的话。
