金融案例

五个金融 Agent demo。

这些案例展示金融 Agent 如何把文档、工单和产品规则转成结构化、可复核的工作流。每个页面都包含蓝图、步骤、截图和模式映射。

阅读路径

先看问题这个金融对象是什么，输入证据是什么。
再看蓝图流程、状态、控制面和输出如何连接。
对照截图用真实界面或命令行输出确认流程。
映射模式把设计落到可复用的 Agent 模式。
