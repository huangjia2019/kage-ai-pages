AI 辅助编程训练营

一套可复用的工程团队 Claude Code 训练营课程。

这套课程已经在是德科技、伦交所（路孚特）、QECon 深圳、奇点智能大会、Packt 出版社和极客时间交付过。 课程沿两条轴组织：横向是 Claude Code 的五大扩展机制，纵向是七个相对独立的教学模块。 每个模块对应一段半天左右的工作坊，落在真实的工程场景上。 全部课程材料放在一个公开仓库里，可以直接 fork 使用：保留你需要的部分，删掉不需要的，按自己团队的节奏跑。

课程结构是一张小型的交叉表。横轴列出 Claude Code 书里讲的五大扩展机制，纵轴列出七个教学模块。每个模块至少触发一种机制，并在一个真实的工程场景里完成练习。

模块

七个模块，每个都可以独立运行。点进 GitHub 模块目录就能拿到讲义、实验脚本和讲师备注。

M1 · 基础与心法

Claude Code 是什么、agent loop 怎么运转、五大扩展机制各自的位置。这一节先把后面所有讨论的共同语言对齐。

git clone https://github.com/huangjia2019/claude-code-engineering.git

M2 · Sub-Agents

用隔离上下文的子任务做委派。构建一个能在真实 PR 流程里跑的代码评审 agent 和测试运行 agent。

cd workshop/modules/M2-sub-agents && cat README.md

M3 · Skills

用 SKILL.md 把能力声明式打包。现场从零写一个金融分析 skill 和一个 API 生成 skill。

cd workshop/modules/M3-skills && cat README.md

M4 · Slash Commands

把日常工程动作包成一句话命令：代码评审、发版说明、值班交接，都收敛到 slash command 入口。

cd workshop/modules/M4-slash-commands && cat README.md

M5 · Hooks

围绕工具调用做事件驱动的自动化。现场写 pre-commit 检查、post-edit lint 和一个无需用户干预的日志分析 hook。

cd workshop/modules/M5-hooks && cat README.md

M6 · MCP 集成

用 Model Context Protocol 接外部工具。用 TypeScript 写一个自定义 MCP server，并把它接进团队的日常工作流。

cd workshop/modules/M6-mcp && cat README.md

M7 · 团队 Playbook

把五大机制组合成一份团队工作流：共享 skill 仓库、插件打包、权限治理和落地 checklist。

cd workshop/modules/M7-team-playbook && cat README.md

过往交付

2025-2026 年间六次具有代表性的交付。每个 instance 目录里包含讲义、议程、脱敏后的反馈记录，以及针对那次受众做的定制化改动。

是德科技

面向测量仪器研发团队的两天线下工作坊，重点放在测试生成和仪器驱动脚手架。

伦交所（路孚特）

面向 LSEG 量化与风控团队：监管文档分析、多 agent 工单审查、Copilot 驱动的规格开发。

QECon 深圳

质量工程大会的工作坊：代码评审、测试生成、故障诊断和效能度量 agent。

奇点智能大会

与 keynote 配套的 workshop，主题是 harness 工程化和 agent 设计模式 catalog。

Packt

配套 Packt 那本 Claude Code 工程化英文书的官方工作坊，把书里案例当现场实验跑。

极客时间直播

极客时间专栏配套的线上工作坊。M1、M2、M3 压缩成三小时版本，面向自学型受众。

如何 fork

整套课程材料是一个公开仓库。要自己跑一遍工作坊，先把仓库 clone 下来，再读一遍流程说明 —— 里面写了受众规模、模块时间分配、实验环境，以及在不同场景下做过哪些定制化改动。

git clone https://github.com/huangjia2019/claude-code-engineering.git

完整的 fork 与交付指南放在 workshop/PROCESS.md。 如果是企业内训或闭门交付，可以从 关于页 上的联系方式联系本人。
